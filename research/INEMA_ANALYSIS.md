## 10. Observações Estratégicas para o CineForge

### O que o INEMA ensina que precisamos dominar

1. **Content2Video e Automação 2026** — pipeline direto para o CineForge: texto/URL → vídeo publicado
2. **OSWork + Skills para Agentes** — infra de agentes que o CineForge vai rodar
3. **Execução Longa** — pattern de agentes assíncronos rodando por horas (nosso pipeline de produção)
4. **projeto-mcp-video e projeto-yt-pub-livesx** — podemos estudar e reusar esses projetos open source

### O que o INEMA NÃO faz (nosso gap)

- Não tem foco em **anúncios de performance** (GBP, Meta Ads, TikTok Ads) com publicação automática
- Não tem **loop fechado de métricas** (gera vídeo mas não sabe se o anúncio converteu)
- Não tem produto de e-commerce especializado (**vídeo de produto para loja**)
- Ensina o "como fazer" mas não entrega o resultado automatizado

### Posicionamento: INEMA ensina, CineForge entrega

O INEMA é um educador. O CineForge é o produto que o aluno INEMA vai querer usar (ou o que o fundador vai querer construir). Há sinergia: podemos ser parceiros (os alunos do INEMA são nosso público) em vez de concorrentes.
